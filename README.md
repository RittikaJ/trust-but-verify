# Trust but Verify

Building Evaluation Systems for Production AI Agents

**Rittika Jindal · Principal Engineer, Thomson Reuters**

25-minute talk + 5-minute Q&A. The resources slide is an appendix.

## Viewing

Open `index.html` directly, or serve this folder with a static HTTP server. No build, dependencies, API keys, external fonts or model calls are required.

- **Slides**: one slide at a time, with arrow keys, Home/End, a slide picker and direct links.
- **Read**: the complete presentation, for sharing after the session.
- **Notes**: speaker notes and per-slide timings.
- **Print**: all slides, including revealed examples. Use the browser’s Save as PDF option.
- **Timer**: manually start, pause or reset. At 25 minutes, the timer changes color for Q&A.

The examples are illustrative. Sources are linked on the relevant slides and on the resources slide. Visual and teaching inspiration: [Evals 101](https://rittikaj.github.io/evals-explained/).

## GitHub Pages

Publish the `main` branch from the repository root. The `.nojekyll` file keeps this a plain static site.
